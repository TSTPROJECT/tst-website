# TST Project website

A responsive one-page bilingual (English/Thai) website for TST Project — Trash so trust.

## Preview locally
Open `index.html` in a browser.

## Before publishing
1. In `index.html`, replace the SeePho product link (`https://www.lemonsqueezy.com/`) with the exact SeePho product URL.
2. The Facebook link is already set to the TST Project page provided by you; update it in `index.html` if the page URL changes.
3. Replace the Fastwork `href="#"` with the service URL(s).
4. Replace `hello@tstproject.example` with an email address you want to publish, or remove that contact link.
5. Check all descriptions, screenshots/illustrations, and links before making the site public.

## Publish for free with GitHub Pages
1. Create a repository for the website on GitHub.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The URL will be shown in Settings → Pages.

No build step, Node.js, or server is required. Google Fonts is optional; if offline, the site uses fallback fonts.
